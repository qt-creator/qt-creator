# Contributing to Qt Creator

Qt Creator uses the Gerrit code review tool of the Qt Project. For instructions
on how to set up the Qt Creator repository to contribute patches back to Qt
Creator, please check:

<https://wiki.qt.io/Setting_up_Gerrit>

See the following page for information about our coding standard:

<https://doc.qt.io/qtcreator-extending/coding-style.html>

To build Qt Creator from source, see [BUILDING.md](BUILDING.md). For information
about the auto tests and other kinds of tests, see [TESTING.md](TESTING.md) and
[HACKING](HACKING).
