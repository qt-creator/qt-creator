Open, configure, build, and edit CMake projects. CMake controls the software
compilation process by using simple configuration files, called
`CMakeLists.txt` files.

![The CMake configuration of a project](https://qtccache.qt.io/images/qtcreator-extension-cmake.webp)

*The build settings of a CMake project*

## Features

- Open CMake projects, and keep the project tree up to date whenever a
  `CMakeLists.txt` file changes
- Use CMake presets for configuring, building, and testing
- View and edit the initial and current CMake configuration
- Edit CMake files with code completion, navigation, help, and formatting
- Add new files to the targets of a project automatically
- Debug and profile CMake scripts

## You also need:

- CMake 3.14 or later

Qt Online Installer installs a CMake version that you can use.
