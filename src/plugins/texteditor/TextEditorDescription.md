The text editing framework behind every editor in Qt Creator. It provides
the common editing features, such as syntax highlighting, searching,
multiple cursors, and snippets, for all languages that Qt Creator supports.

![Incremental search in the editor](https://qtccache.qt.io/images/qtcreator-extension-texteditor.webp)

*Incremental search highlights all matches in the editor*

## Features

- Syntax highlighting for many languages through Kate syntax definitions,
  which you can download and update
- Code folding and block highlighting to see and collapse code that belongs
  together
- Multiple cursors that apply your edits at all cursor positions at once
- Incremental search and replace, also with regular expressions
- Code snippets in the completion menu
- Bookmarks, split editor views, and recorded text editing macros
