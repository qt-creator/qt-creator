Work with Git repositories from Qt Creator. View the history of your files
and projects, compare and commit changes, and manage branches without
switching to the command line.

![The Git log of a repository](https://qtccache.qt.io/images/qtcreator-extension-git.webp)

*The history of a repository in the Git log*

## Features

- Instant blame shows the author and date of the current line in the editor
- Compare changes side by side or in a unified view, and stage individual
  chunks or lines
- View the log of a file, a project, or the repository, with a commit graph
  and filters
- Create, check out, merge, and compare branches in the **Git Branches** view
- Reorder, edit, squash, or discard commits with interactive rebase
- Put changes aside with the stash
- Review code with Gerrit

## You also need:

- Git
