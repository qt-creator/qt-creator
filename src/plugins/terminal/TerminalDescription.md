Work in a shell without leaving Qt Creator. The terminal runs in an output
view next to your code, so you can run commands, follow their output, and
jump into the files they mention.

![Terminal running Git and CMake commands](https://qtccache.qt.io/images/qtcreator-extension-terminal.webp)

*A terminal in the Terminal output view*

## Features

- Open a terminal in the **Terminal** output view, or start one from the
  project directory with **Open Terminal Here** in the **Projects** and
  **File System** views
- Run several shells side by side in tabs
- Ctrl+click links, files, and folders to open them in a browser, the
  editor, or a file manager
- Search the output with Ctrl+F
- Control Qt Creator from the shell with the `qtc` command and insert
  Qt Creator variables into the command line
- Run applications in the terminal with **Run in terminal** in the run
  settings
